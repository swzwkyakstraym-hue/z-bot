عن الموقع

أنشئ موقع ويب ضخم واحترافي جدًا خاص بعالم النقابات والجروبات، بتصميم Gaming / Anime فاخر ومتحرك، ويكون الموقع كأنه منصة كاملة وليس صفحة عادية.

الفكرة:
منصة تعرض مجموعة كبيرة من النقابات والجروبات، وكل نقابة لها بطاقة خاصة بها ومعلوماتها وتصميمها وشعارها وبانرها وأعضاءها وترتيبها.

اجعل النظام Data-Driven بحيث يمكن إضافة نقابات جديدة بسهولة من Array في JavaScript بدون إعادة بناء الصفحة.

الصفحة الرئيسية:
- Hero section ضخم وفخم.
- اسم الموقع بتأثير Neon.
- خلفية Anime/Gaming أصلية باستخدام CSS وSVG محلي.
- جملة تعريفية قصيرة.
- أزرار واضحة مثل:
استكشف النقابات
الترتيب
البحث
- إحصائيات متحركة مثل عدد النقابات والأعضاء والنشاط.
- قسم لأفضل النقابات.
- قسم للنقابات الجديدة.
- قسم لأكثر النقابات نشاطًا.
- تأثيرات ظهور أثناء النزول في الصفحة.

قسم النقابات:
اعرض جميع النقابات في Cards احترافية.
كل Card تحتوي على:
- بانر خاص بالنقابة.
- شعار أو Icon.
- اسم النقابة.
- وصف قصير.
- عدد الأعضاء.
- مستوى النقابة.
- نقاطها.
- ترتيبها.
- نسبة النشاط.
- زر "عرض النقابة".

أضف:
- Search حقيقي للبحث عن النقابات.
- Filter حسب المستوى.
- Filter حسب النشاط.
- ترتيب حسب النقاط.
- ترتيب حسب عدد الأعضاء.
- ترتيب حسب النشاط.
- زر إعادة الترتيب.
- Empty State لو مفيش نتائج.

صفحة تفاصيل النقابة:
عند الضغط على أي نقابة افتح صفحة أو Modal احترافي يحتوي على:
- Banner كبير.
- شعار النقابة.
- اسمها.
- وصفها.
- القائد.
- عدد الأعضاء.
- النقاط.
- المستوى.
- الترتيب.
- نسبة النشاط.
- قائمة أعضاء تجريبية.
- إحصائيات.
- سجل إنجازات.
- أزرار التواصل والانضمام.
- زر رجوع.

قسم الترتيب:
اعمل Leaderboard حقيقي للنقابات.
اعرض المراكز:
🥇 المركز الأول
🥈 المركز الثاني
🥉 المركز الثالث
ثم باقي المراكز.
كل مركز يحتوي على اسم النقابة والنقاط والأعضاء والنشاط.
اعمل التصميم بشكل Gaming فاخر.

قسم الأعضاء:
اعمل بطاقات للأعضاء التجريبيين.
كل عضو يحتوي على:
- الاسم.
- الرتبة.
- النقاط.
- مستوى النشاط.
- النقابة التابعة له.
- Badge مناسب.

التفاعل:
كل الأزرار لازم تكون شغالة.
البحث والفلترة والترتيب لازم تكون JavaScript حقيقية.
التنقل بين الأقسام يكون سلس.
استخدم Modals عند الحاجة.
استخدم Toast Notifications للتفاعل.
أضف Tabs في الأماكن المناسبة.
أضف Counters متحركة.
أضف Hover Effects.
أضف Scroll Animations.
أضف Loading Animation خفيفة.
أضف زر للعودة لأعلى الصفحة.
أضف Dark Gaming UI احترافي.

التصميم:
- Dark Mode أساسي.
- Neon Gaming.
- Anime-inspired.
- Glassmorphism.
- Cards بحدود مضيئة.
- Glow Effects.
- Gradients.
- خطوط جميلة.
- Responsive بالكامل للموبايل والكمبيوتر.
- لا تجعل التصميم مزدحمًا.
- استخدم مساحات جيدة بين العناصر.
- اجعل الموقع سريع وخفيف.

اللغة:
الموقع عربي RTL بشكل أساسي، مع دعم English داخل العناصر المهمة.
استخدم أسماء النقابات كما هي تمامًا.
لا تغيّر أسماء النقابات.

المهم جدًا:
هذا الوصف عبارة عن DEVELOPMENT SPECIFICATION وليس نصًا يتم عرضه داخل الموقع.
كل نقطة هنا يجب تحويلها إلى HTML/CSS/JavaScript حقيقي.
لا تكتب شرحًا للمواصفات داخل الموقع.
لا تستخدم Lorem Ipsum.
لا تضع TODO.
لا تضع أقسام وهمية.
لا تجعل الأزرار مجرد شكل بدون وظيفة.

الصور:
لا تعتمد على Pinterest أو مواقع خارجية وقت تشغيل الموقع.
لو احتجت صورًا أو بانرات، أنشئ Visuals أصلية باستخدام SVG/CSS محلي أو استخدم Assets محلية.
كل نقابة يجب أن يكون لها شكل بصري مختلف ومميز.
اجعل البانرات أصلية ومناسبة لطابع كل نقابة.

الأداء:
الموقع Static ويمكن تشغيله على GitHub Pages.
استخدم HTML + CSS + Vanilla JavaScript فقط.
لا تستخدم Backend.
لا تعتمد على CDN أو مكتبات خارجية.
كل الروابط الداخلية Relative.
اجعل الموقع يعمل حتى بدون إنترنت بعد تحميله.
